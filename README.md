# Отчет по безопасности веб-ресурса (Security Audit)

В ходе анализа параметров безопасности сайта были выявлены следующие показатели и уязвимости. Ниже приведена сводная таблица состояния системы.

## Сводка аудита

| № | Находка | Статус |
| :---: | :--- | :--- |
| 1 | Сертификат действителен менее 30 дней (истек / недействителен) | ❌ Проблема |
| 2 | Панель администратора доступна извне | ❌ Проблема |
| 3 | Используется защищенный протокол HTTPS | ✅ Норма |
| 4 | Наличие защиты от брутфорса на входе | ✅ Норма |
| 5 | Наличие двухфакторной аутентификации (СМС-код для защиты аккаунта) | ✅ Норма |
| 6 | Есть политика конфиденциальности | ✅ Норма |
| 7 | Контакты указаны | ✅ Норма |

Проблемы
1. Просроченный или недействительный SSL-сертификат (действителен менее 30 дней)
2. Открытая панель администратора, доступная извне


| № | Проверка / Выявленная проблема | Категория CIA | Критичность | Обоснование / Текущий статус |
| :-: | :--- | :-: | :--- | :--- |
| **1** | **Истекающий SSL-сертификат** (срок действия менее 30 дней) | C, A | **Высокий** | Сертификат скоро станет недействительным. Браузеры начнут блокировать вход на сайт, нарушая доступность (A) и доверие к конфиденциальности (C). |
| **2** | Использование протокола HTTPS | C | Информационный | **Проверка пройдена (ДА):** Замок на сайте есть, трафик зашифрован. Риск перехвата данных в открытом виде отсутствует. |
| **3** | Доступность панели администратора извне | C, I, A | Информационный | **Проверка пройдена (НЕТ):** Панель администратора скрыта от внешнего доступа. Автоматические сканеры не смогут её обнаружить. |
| **4** | Защита от брутфорса на входе | A, C | Информационный | **Проверка пройдена (ДА):** Настроена защита от автоматизированного подбора паролей, что снижает нагрузку на сервер и защищает аккаунты. |
| **5** | Отсутствие двухфакторной аутентификации (2FA) | C, I | Информационный | **Проверка пройдена (ДА):** Для защиты аккаунта Пятёрочки реализована отправка одноразовых SMS-паролей на привязанный телефон пользователя. |
| **6** | Отсутствие политики конфиденциальности и контактов | C | Информационный | **Проверка пройдена (ДА):** Документы и контактные данные присутствуют на сайте, риски нарушения законодательства (комплаенса) минимизированы. |
