# Отчет по безопасности веб-ресурса (Security Audit)

В ходе анализа параметров безопасности сайта были выявлены следующие показатели и уязвимости. Ниже приведена сводная таблица состояния системы.

| № | Находка | Статус |
| :---: | :--- | :--- |

## Детализация критических уязвимостей (Issues)

### 1. Проблема с SSL-сертификатом
* **Описание:** Срок действия SSL/TLS-сертификата составляет менее 30 дней, либо он некорректно настроен.
* **Риски:** Браузеры пользователей начнут помечать сайт как небезопасный, что приведет к потере трафика и снижению доверия.
* **Решение:** Обновить сертификат (например, через Let's Encrypt) и настроить автоматическое продление (cron-задача для `certbot`).

### 2. Открытая панель администратора
* **Описание:** Страница авторизации администратора доступна для внешних запросов из глобальной сети.
* **Риски:** Повышенная угроза целевых атак и попыток обхода авторизации, несмотря на наличие защиты от брутфорса.
* **Решение:** 
  * Ограничить доступ к админ-панели на уровне веб-сервера (Nginx/Apache) по списку доверенных IP-адресов.
  * Перенести панель на нестандартный URL-адрес.
  * Настроить доступ к панели строго через корпоративный VPN.
